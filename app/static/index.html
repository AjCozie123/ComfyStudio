How to add a workflow from ComfyUI
  1. Get the workflow file. Any ComfyUI workflow saved as a .json file works: one you downloaded, one from the ComfyUI template gallery, or your own (in ComfyUI: Workflow → Save or Export). Grouped nodes (subgraphs) are fine; the app opens them for you. If you set the workflow up in ComfyUI's App Mode, the app uses the controls you chose there.
  2. Upload it. On this page, tap + Upload workflow (top right) and choose the file.
  3. Wait a moment. The app opens the workflow the same way ComfyUI does and sets it up for you: your prompt, pictures, size, seed and so on go into the app's own buttons. It tells you in one line what the workflow makes. Most workflows say ✓ Ready to use.
  4. If it needs something, it asks one plain question (for example which text box is the prompt) or shows an Install button for an add-on your ComfyUI doesn't have yet.
  5. A file with several workflows in it (one for text to video, one for image to video ...) shows a list. Each one becomes its own choice; untick any you don't want.
  6. Tap Add. The app offers to use it straight away. It also appears on this page, marked Yours.
  7. Use it. Tap Use on its card. You go to Create with it selected; type a prompt and press the send arrow. The pills below the prompt (Size, Seed, LoRA and so on) now control this workflow.
  8. Switch back any time with the sliders button next to the send arrow (Settings → Engine), or tap Use on another card here. Delete on a card removes only that uploaded engine.

Settings the app doesn't control keep the values saved in the workflow. Built-in prompt enhancers inside a workflow are switched off, because the app's own Enhance pill does that job.

      My words

      Always add

      Keep clothing

      All picture engines. When your prompt doesn't mention clothes (turn her, sit her down, change the light), the app adds one short "keep their clothing the same" line, so the edit can't change or remove what they're wearing. If your prompt is about clothes (add a jacket, wear the dress from Picture 2, remove the hat), nothing is added and your words decide. Body swaps and putting someone into a scene are left alone too, since their clothes come from the other picture.

      Keep image quality

      All picture edits. Adds one line so the result looks like the same photograph: the same sharpness, grain, skin and fabric texture, colours and lighting, with only your change. If your prompt changes the light (sunset, relight) the light isn't locked; if it changes quality (sharpen, restore) quality isn't locked; style changes (anime, black and white) are left alone.
